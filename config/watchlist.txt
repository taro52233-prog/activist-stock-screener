# 監視リスト（バリュー参考）
# アクティビストの大量保有が無い銘柄でも、ここに証券コードを1行1つ書けば
# 毎日パイプラインが株価・財務・チャートを取得してダッシュボードに表示します。
# アクティビストの「買いゾーン（追随戦略）」は非対象で、PBR1倍（＝BPS株価）を
# 買い目安の基準にした「バリュー判定（割安/割高）」を表示します。
#
# 例（先頭の # を外すと有効になります）:
7203   # トヨタ自動車（動作確認用のサンプル。不要なら行頭に # を付けてください）
8035   # 東京エレクトロン（ユーザー登録）
AAPL   # Apple（米国株の動作確認用サンプル）
# 8306   # 三菱UFJフィナンシャル・グループ
#
# アプリの「銘柄を開く」から任意コードを入力すると、ここに未登録でも
# その場でブラウザに監視登録でき、登録リストのコピーもできます。
SMH   # アプリから登録
